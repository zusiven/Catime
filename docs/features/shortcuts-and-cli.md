# 快捷键与命令行

Catime 的操作入口包括托盘菜单、可配置的全局快捷键和命令行参数。全局快捷键可在托盘菜单的快捷键设置中修改；新安装配置中的快捷键默认值为 `None`。

## 全局快捷键

可配置的动作包括：显示当前时间、正计时、倒计时、三个快捷倒计时、启动番茄钟、显示/隐藏窗口、切换编辑模式、暂停/继续、重启计时、输入自定义倒计时、切换毫秒显示和切换置顶状态。

## 时间参数

启动程序时可传入时间表达式来开始倒计时：

```text
catime.exe 25m
catime.exe 1h30m
```

程序已在运行时，第二次启动会把时间参数转发给现有实例。支持的时间格式见[计时模式](time-management.md#时间输入)。

## 运行中实例的短命令

当命令传递给已运行实例时，以下短命令会映射到应用动作：

| 命令 | 动作 |
| --- | --- |
| `s` | 切换当前时间显示 |
| `u` | 启动正计时 |
| `p` | 启动番茄钟 |
| `r` | 重启当前计时 |
| `h` | 显示命令帮助 |
| `e` | 切换编辑模式 |
| `v` | 显示或隐藏窗口 |
| `pr` | 暂停或继续 |
| `q1`、`q2`、`q3` | 启动对应的快捷倒计时 |
| `pN` | 选择第 N 个快速时长 |

这些单字母和短命令由单实例转发路径处理。程序未运行时，启动参数按时间输入解析；因此文档示例中的通用 CLI 用法应使用时间表达式。
