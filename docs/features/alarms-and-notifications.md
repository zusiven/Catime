# 闹钟与通知

闹钟按本地时钟的小时和分钟触发；通知模块显示倒计时结束、闹钟和插件消息。闹钟路径会尝试播放通知声音；插件 `<notify>` 标签的处理路径只显示通知。

## 闹钟

- 最多保存 10 个闹钟。
- 每个闹钟包含时间、自定义消息、启用状态和重复规则。
- 重复规则支持单次、每天或指定星期；星期编号为 `0` 到 `6`，其中 `0` 表示星期日。重复规则的星期列表为空时按每天处理。
- 单次闹钟触发后会自动禁用；用户可以在托盘菜单中新增、启停或清除闹钟。
- 闹钟配置写入 `%LOCALAPPDATA%\Catime\config.ini` 的 Alarm 配置项。

计时更新路径会调用 `CheckAlarmTriggers()`。该函数读取本地时间，只在秒值为 `0` 时继续比对，并记录上次触发的小时和分钟以避免同一分钟重复触发。这个源码条件不等于已验证的准点调度保证；恢复或忙碌时是否会错过该秒，本次未在 Windows 上运行验证。

### 睡眠恢复时的补触发状态

源码实现了 `CheckMissedAlarms()`，逻辑会查找当前本地时间之前 1 至 5 分钟内的启用闹钟。不过当前仓库中没有找到该函数的调用点；窗口的系统恢复处理调用 `Timer_OnSystemResume()` 并重建托盘动画，没有调用补发闹钟函数。因此不能据此认为睡眠恢复后会补发闹钟通知。源码接线图见[项目集成与验证边界](../project-integration.md)。

## 通知

通知设置包含显示方式、显示时长、透明度、位置和尺寸；声音设置包含音频文件和音量。源码提供 Catime 通知窗、系统模态提示和托盘提示三条显示路径。配置枚举中的 `OS` 会进入托盘提示回退路径，不是 Windows 原生 toast 通知。Catime 通知窗失败时，源码包含向模态提示和托盘提示回退的处理；这些路径的桌面表现本次未实测。

闹钟触发会显示闹钟消息并尝试播放通知声音。倒计时结束时是否播放声音，取决于所选超时动作和声音设置。

## 倒计时超时动作

倒计时可配置以下动作：

- 显示消息
- 锁定屏幕、关机、重启或睡眠
- 打开指定文件或网站
- 切换到显示当前时间或正计时

这些动作属于倒计时结束处理；闹钟触发行为独立于倒计时动作。
