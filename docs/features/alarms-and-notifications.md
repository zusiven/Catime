# 闹钟与通知

闹钟按本地时钟的小时和分钟触发；通知模块显示倒计时结束、闹钟和插件消息。闹钟路径会尝试播放通知声音；插件 `<notify>` 标签的处理路径只显示通知。

## 闹钟

- 最多保存 10 个闹钟。
- 每个闹钟包含时间、自定义消息、启用状态和重复规则。
- 重复规则支持单次、每天或指定星期；星期编号为 `0` 到 `6`，其中 `0` 表示星期日。重复规则的星期列表为空时按每天处理。
- 单次闹钟触发后会自动禁用；用户可以在托盘菜单中新增、启停、编辑或删除单个闹钟，也可以清除全部。
- 闹钟配置写入 `%LOCALAPPDATA%\Catime\config.ini` 的 Alarm 配置项。整组列表通过一次原子写入保存；新增、编辑、启停、删除或清空失败时会回滚本次修改并提示错误。单次闹钟触发后若写入失败，本次运行仍会禁用该闹钟并提示重启后可能再次触发。
- 外部编辑 `config.ini` 后，程序会重新加载闹钟列表。无效时间或重复日配置会禁用对应闹钟，不会按午夜或意外星期触发。

闹钟使用独立于计时显示和倒计时状态的 1 秒窗口定时器；显示当前时间、暂停计时或隐藏主窗口时仍会检查。调度按本地日期和时间识别每次触发，并补偿不超过 5 分钟的处理延迟。超过补偿窗口、系统关机期间或 Windows 实际调度延迟的行为，本次未在 Windows 上运行验证。

同一分钟内到期的多个闹钟会合并为一条通知，并只播放一次声音。

### 睡眠恢复

系统恢复消息会调用 `CheckMissedAlarms()`；它沿用常规调度器，在 5 分钟补偿窗口内检查睡眠期间到期的闹钟，并按闹钟发生的本地日期判断指定星期规则。补发路径的 Windows 行为尚未实机验证；源码接线见[项目集成与验证边界](../project-integration.md)。

## 通知

通知设置包含显示方式、显示时长、透明度、位置和尺寸；声音设置包含音频文件和音量。源码提供 Catime 通知窗、系统模态提示和托盘提示三条显示路径。配置枚举中的 `OS` 会进入托盘提示回退路径，不是 Windows 原生 toast 通知。Catime 通知窗失败时，源码包含向模态提示和托盘提示回退的处理；这些路径的桌面表现本次未实测。

闹钟触发会显示闹钟消息并尝试播放通知声音。自定义消息以 UTF-8 保存；同一时间多个闹钟的消息会换行合并。倒计时结束时是否播放声音，取决于所选超时动作和声音设置。

## 倒计时超时动作

倒计时可配置以下动作：

- 显示消息
- 锁定屏幕、关机、重启或睡眠
- 打开指定文件或网站
- 切换到显示当前时间或正计时

这些动作属于倒计时结束处理；闹钟触发行为独立于倒计时动作。
