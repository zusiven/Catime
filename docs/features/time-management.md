# 计时模式

Catime 的时间显示和计时状态由 timer 模块维护。主窗口以固定间隔刷新显示；计时计算依据单调时钟，避免单纯累计 UI 刷新次数造成长时间漂移。

## 模式

| 模式 | 行为 |
| --- | --- |
| 当前时间 | 显示本地系统时间，可配置 12/24 小时制和秒数显示。 |
| 倒计时 | 从指定时长递减，结束后执行配置的超时动作。 |
| 正计时 | 从启动时刻累计经过时间。 |
| 番茄钟 | 按配置的时长数组顺序切换；数组完整执行一次计为一轮，达到循环数后结束。 |

番茄钟启动时会复制当前配置的时长数组和循环数，运行中配置变化不会改动这次运行的快照。默认时长数组是 `1500,300,1500,600` 秒（25 分钟、5 分钟、25 分钟、10 分钟），默认循环数为 1。源码以数组下标推进阶段，不按“工作”或“休息”标签赋予数组各项固定含义。配置文件位置和分组见[配置与语言](configuration-and-language.md)。

## 时间输入

时间解析器接受带单位的时长、简写数字和目标时刻。常见写法：

| 输入 | 含义 |
| --- | --- |
| `25m` | 25 分钟 |
| `1h30m` | 1 小时 30 分钟 |
| `90s` | 90 秒 |
| `25` | 25 分钟（未带单位时按分钟处理） |
| `130 20` | 130 分钟 20 秒 |
| `1 30 15` | 1 小时 30 分钟 15 秒 |
| `14 30t` | 倒计时到下一次 14:30；若今天已过，则指向次日 |

带 `t` 的目标时刻格式用于倒计时输入；时间解析器的完整支持格式见 [`time_parser.h`](../../include/utils/time_parser.h)。

## 结束动作

倒计时结束时可选择消息提示、锁定、关机、重启、打开文件、切换到当前时间、切换到正计时、打开网站或睡眠。实际动作由 Timer 设置中的超时动作选项决定。

## 计时更新

高精度定时器在工作线程中发消息给主窗口，绘制和状态转换仍由窗口线程处理。多媒体定时器不可用时会退回 `SetTimer`。系统睡眠恢复时，计时模块会修正单调时钟与系统 Tick 之间的差值。
